# ApexAlgo — ربات معامله‌گر خودکار متاتریدر ۵

سیستم کامل معامله‌گری خودکار برای متاتریدر ۵: یک Expert Advisor حرفه‌ای با
تشخیص رژیم بازار و موتور سخت مدیریت ریسک، به‌همراه پنل کنترل موبایل و مرورگر.

---

## ⚠️ قبل از هر چیز بخوانید

**هیچ ربات معامله‌گری نمی‌تواند سود را تضمین کند.** هر کسی که خلافش را بگوید
یا در اشتباه است یا در حال فروش چیزی به شماست.

این پروژه چیزی که ارائه می‌دهد **انضباط** است، نه پیش‌بینی: قوانین بدون احساسات
اجرا می‌شوند، حجم هر معامله دقیقاً از ریسک محاسبه می‌شود، هر پوزیشن حد ضرر
سمت-سرور دارد، و محدودیت‌های ضرر روزانه و کلی به‌صورت سخت اجرا می‌شوند.

مسیر اعتبارسنجی (بک‌تست ← Walk-Forward ← دمو ← واقعی کوچک) در مستندات آمده و
**هیچ مرحله‌ای قابل حذف نیست**.

### 📱 یک واقعیت فنی مهم

> **اپلیکیشن موبایل متاتریدر نمی‌تواند Expert Advisor اجرا کند.**
> این محدودیت خودِ متاتریدر است، نه این پروژه.

مغز ربات همیشه روی **ویندوز** (کامپیوتر یا VPS) اجرا می‌شود. گوشی از طریق
داشبورد وب و ربات تلگرام، آن را می‌بیند و کنترل می‌کند.

---

## معماری

```
┌───────────────────────────────┐
│  ویندوز / VPS  ۲۴ ساعته        │
│  متاتریدر ۵ + ApexAlgo EA     │   ← مغز مستقل
└──────────────┬────────────────┘
               │ فقط درخواست خروجی HTTPS
               ▼
   ┌───────────────────────┐
   │  سرور کنترل (Flask)    │
   └─────┬───────────┬─────┘
         ▼           ▼
   داشبورد PWA   ربات تلگرام
  (گوشی + کامپیوتر)  (گوشی)
```

**اصل طراحی:** سرور کنترل یک وسیله راحتی است، نه یک وابستگی. اگر شبکه قطع شود،
EA طبق قوانین محلی خودش به کار ادامه می‌دهد و تمام محافظ‌های ریسک فعال می‌مانند.

## امکانات

### Expert Advisor (MQL5)
- **تشخیص رژیم بازار** — ترکیب ADX، Efficiency Ratio کافمن و پهنای باند بولینگر
- **ترکیب چند استراتژی** — روند (شکست دانچیان + پولبک + مومنتوم) و
  رنج (بولینگر + RSI)، با امتیاز پیوسته ‎-۱ تا ‎+۱
- **تأیید تایم‌فریم بالاتر** — به‌عنوان وزن و به‌عنوان دروازه
- **حجم بر اساس ریسک** — با `TICK_VALUE` و `TICK_SIZE` خود بروکر، نه پیپ ثابت
- **سقف‌های سخت** — ضرر روزانه، حداکثر افت با کلید توقف، استریک ضرر،
  تعداد معاملات، تمرکز ارزی، سلامت مارجین
- **کاهش تدریجی ریسک در افت** — هرچه افت بیشتر، ریسک کمتر
- **مدیریت معامله** — سربه‌سر، برداشت پله‌ای، تریلینگ ATR (فقط تنگ‌شونده)، خروج زمانی
- **فیلترها** — اسپرد نسبت به ATR، جلسه معاملاتی، روز هفته، تخت شدن آخر هفته،
  تقویم اقتصادی، نوسان غیرعادی
- **اجرای مقاوم** — تشخیص خودکار حالت پرشدن (رفع خطای ۱۰۰۳۰)، تلاش مجدد
  هوشمند برای ریکوت، اصلاح خودکار حد ضرر نامعتبر
- **چند نماد** از یک چارت
- **لاگ کامل CSV** — هر تصمیم قابل ردیابی است

### پنل کنترل (Python)
- داشبورد PWA موبایل-اول، نصب‌شدنی روی صفحه اصلی گوشی
- نمودار سرمایه، پوزیشن‌های زنده، وضعیت محافظ‌ها، تاریخچه رویدادها
- دکمه‌های توقف / ادامه / بستن همه / توقف اضطراری، همراه با تأیید
- تغییر درصد ریسک با اسلایدر (با سقف سمت سرور)
- ربات تلگرام با اعلان فوری و تأیید دکمه‌ای
- احراز هویت توکن، نشست امضاشده، هدرهای امنیتی، محدودیت تلاش ورود

### ابزارها
- `walkforward.py` — تحلیل Walk-Forward کامل با حکم خودکار
- `mt5_bridge.py` — آمار عملکرد، خروجی CSV، و **نگهبان مستقل** سرمایه

## شروع سریع

```powershell
# ویندوز
cd trading-bot\scripts
powershell -ExecutionPolicy Bypass -File install_windows.ps1
```

```bash
# لینوکس / مک (فقط سرور کنترل)
cd trading-bot/scripts
./run_server.sh
```

سپس:
1. در متاتریدر **F4** ← فایل `ApexAlgoEA.mq5` ← **F7** برای کامپایل
2. **Tools ← Options ← Expert Advisors** ← تیک WebRequest ← افزودن `http://127.0.0.1:8800`
3. EA را روی چارت بکشید، `InpRemoteToken` را وارد کنید، **Allow Algo Trading** را تیک بزنید
4. `http://127.0.0.1:8800` را باز کنید

جزئیات کامل در [`docs/03-install-windows.md`](docs/03-install-windows.md).

## مسیر اعتبارسنجی

```
۱. بک‌تست            آیا منطق کار می‌کند؟                   چند ساعت
۲. Walk-Forward      آیا بیش‌برازش نشده؟                    یک روز
۳. دمو               آیا با اسپرد و لغزش واقعی سود دارد؟     حداقل ۴ هفته
۴. واقعی کوچک        آیا در عمل درست اجرا می‌شود؟            ۸ هفته
۵. افزایش تدریجی     فقط بعد از ۳ ماه نتیجه پایدار
```

**هیچ مرحله‌ای قابل حذف نیست.** مرحله ۳ مخصوصاً — بک‌تست اسپرد متغیر، ریکوت،
لغزش و قطعی اینترنت را شبیه‌سازی نمی‌کند.

## انتظارات واقع‌بینانه

| معیار | عدد واقعی یک سیستم حرفه‌ای |
|---|---|
| بازده سالانه | ۱۰٪ تا ۳۰٪ با ریسک کنترل‌شده |
| حداکثر افت | ۱۰٪ تا ۲۰٪ حتی در سیستم‌های خوب |
| دوره ضرر | ۲ تا ۳ ماه پشت‌سرهم، کاملاً طبیعی |
| ماه‌های ضررده | ۳۰٪ تا ۴۰٪ ماه‌ها |

با تنظیمات پیش‌فرض (ریسک ۰.۵٪، سقف افت ۱۰٪) هدف **بقا و رشد آهسته** است.

## سلب مسئولیت

این نرم‌افزار برای مقاصد آموزشی و پژوهشی ارائه شده است. معامله در بازارهای مالی
ریسک از دست دادن سرمایه دارد. عملکرد گذشته تضمینی برای نتایج آینده نیست.

مسئولیت کامل اعتبارسنجی، تنظیم و استفاده از این سیستم بر عهده شماست. هرگز با
پولی معامله نکنید که توان از دست دادنش را ندارید.
